Sobre nuestro proyecto

Somos estudiantes de Ingeniería de Software y, mediante este proyecto, buscamos fortalecer nuestras habilidades en el uso de Git y GitHub como herramientas fundamentales para el desarrollo de software. Estas plataformas nos permiten gestionar y almacenar nuestros proyectos, llevar un control organizado de los cambios realizados y facilitar la colaboración y el trabajo en equipo.
